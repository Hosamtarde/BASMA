# ADR-0007 — Localization
Status: Accepted · 2026-11-06

## Decision
A small in-house `I18nService` (no library): `ar.json` / `en.json` catalogs, `{param}` interpolation, language from `Accept-Language` (fallback `ar`). The API returns `code` + `params` + localized `message`. A CI script fails when the two catalogs have different keys. The DB stores codes; audit entries store code + params and are rendered on read.

## Why not nestjs-i18n
The need is a key lookup plus interpolation; a dependency is not justified yet (YAGNI). Revisit if plural rules grow.
